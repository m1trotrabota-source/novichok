# Новичок

Помощник первых 90 дней для оптово-розничной компании спорттоваров. Прототип на учебных данных, все люди выдуманы.

Для кого:
- новичок: план адаптации на 90 дней по своей роли с отметками и поиск ответов по базе внутренних инструкций, у каждого ответа указан источник;
- HR: список всех новичков со статусом (в графике, внимание, риск), статус считается от доли пунктов плана, которые должны быть закрыты к текущему дню.

Запуск:
- любой статический сервер, например `npx vite` или `python -m http.server`, затем открыть index.html;
- сборки нет, это чистые HTML, CSS и JS без зависимостей.

Структура:
- index.html — разметка;
- styles.css — стили;
- src/data.js — планы по ролям, учебные сотрудники, база инструкций;
- src/search.js — поиск по базе: ключевые слова, синонимы, стоп-слова;
- src/app.js — отрисовка и логика, отметки хранятся в localStorage браузера.

Следующий шаг при внедрении: заменить src/data.js на реальные инструкции и список новичков из Битрикс24.
